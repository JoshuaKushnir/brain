## Vault rules

- Common names are short and arise from history, geography, or culture.
- Mechanics and lore must explain one another.
- One Aspect represents devotion; additional Aspects represent divine betrayal.
- Luminance resists unfamiliar Darkness; it is not mana.
- Death preserves identity, while Darkness tries to revise it.
