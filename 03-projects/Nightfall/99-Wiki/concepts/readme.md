# README

## Definition

A **README** is a foundational documentation file that describes the organization, taxonomy, and navigation of a project's repository—in this case, the Nightfall vault. It enumerates numbered sections (e.g., 00‑MOC, 01‑Canon) each representing a distinct content category such as entry points, canon lore, world‑building, systems, gameplay design, implementation plans, reference material, and archived copies. The README also provides a navigation cue directing contributors to begin at the Nightfall Home page located in the 00‑MOC folder, thereby establishing a clear roadmap for consistent content creation and retrieval.

## Key Characteristics

- **Section‑based taxonomy**: Uses two‑digit identifiers (00‑, 01‑, …) to delineate content categories.  
- **Purpose statements**: Each section includes a concise description of its intended use.  
- **Navigation guidance**: Points users to the Nightfall Home page as the entry point.  
- **Contributor orientation**: Serves as a roadmap for where specific types of information should be stored.  
- **Version‑agnostic**: Functions as a static reference independent of the underlying file formats.

## Applications

- **Onboarding**: New contributors consult the README to understand the vault’s structure before adding or modifying content.  
- **Documentation governance**: Maintains consistent taxonomy across the Nightfall project, reducing duplication and misplacement of files.  
- **Search optimization**: By defining clear categories, the README enables easier retrieval of assets through folder navigation or search tools.  
- **Project planning**: The “implementation plans” section guides developers on upcoming work and documentation milestones.
