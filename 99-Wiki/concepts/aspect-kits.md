# Aspect kits

## Definition

Aspect kits are specialized character customization bundles that define a player's mechanical identity and progression path. There are exactly five distinct Aspect kits within the game architecture, serving as a foundational pillar of character development alongside homeland, faction, and Oath.

## Key Characteristics

- **Mandatory Set**: Exactly five unique kits that must be fully implemented.
- **Structural Integration**: Functions as a primary character identity marker.
- **Systemic Dependency**: Integrates directly with game resource systems to manage balance and character state.
- **Identity Framework**: Complements existing systems like [[concepts/twelve-mortal-peoples|homeland]], [[faction]], and [[Oath]].

## Applications

- Defining specialized character archetypes during the creation process.
- Controlling character progression pathing and skill accessibility.
- Managing resource allocation and consumption balance in relation to [[Health]] and other vital statistics.
