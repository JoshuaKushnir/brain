# Nightfall

## Description

Nightfall is a project initiative encompassing both a documented world-building vault and an associated Roblox game codebase. The vault serves as the repository for canonical lore, while the game repository functions as the technical implementation. Currently, there is an ongoing effort to align the canonical ring designations defined in the vault with the implementation labels found within the [[entities/nightfall|Nightfall]] game repository, as a mismatch exists where the codebase labels Ring 4 as "Gloam" while vault canon identifies Gloam as Ring 2 and Night as Ring 4. Beyond its status as a project, "Nightfall" refers to a catastrophic historical event characterized as a period of profound global instability and existential challenge, serving as the definitive transition point between the era of the ancients and the emergence of the twelve mortal peoples. The project underwent a structured migration process to organize these documentation assets, ensuring that legacy file versions were preserved during the transition to a canonical structure.

The project further faces synchronization challenges between its narrative documentation and technical codebase, particularly regarding geographic zoning and map scale. Additionally, persistent architectural issues arise from the existence of divergent folder structures, characterized by both spaced and hyphenated naming conventions, which complicates ongoing content management. As a historical event, it represents a global era of extreme hardship and systemic collapse, acting as a catalyst for the intervention of the [[concepts/patron-gods|Patron Gods]] and the establishment of the [[concepts/survival-covenants|survival covenants]].

The project further functions as a comprehensive knowledge management initiative, currently comprising 121 markdown notes and a network of 590 internal wikilinks. It maintains a high level of structural integrity, ensuring that the documentation architecture remains consistent with zero unresolved targets. The project incorporates diverse elements such as gods, rings, peoples, systems, and historical events, utilizing a standardized documentation framework to maintain rigour across both its narrative lore and technical implementation. This systematic approach ensures that complex world-building components remain consistent as they are integrated into the broader architecture.

Nightfall serves as the central project and fictional universe, acting as the primary context for the history and evolution of all entities defined within the system. Historians use the event to define the "Pre-Nightfall" and "Post-Nightfall" chronological eras, while theological studies reference it to justify the necessity of divine protection and the origin of mortal obligations to the divine. This foundational role ensures that the interconnected lore and technical structures remain anchored within a single, cohesive narrative framework.
