# Void

## Description

Void is a fundamental metaphysical Aspect characterized by restraint, separation, silence, boundaries, and accepted absence. While it represents a state of nothingness that paradoxically defines the boundaries of movement and consumption, it is explicitly distinguished from the concept of [[99-Wiki/concepts/darkness|Darkness]]. It is instrumental in creating [[concepts/confluence|Confluences]], acting as the necessary canvas for the interactions of [[entities/ash|Ash]]. Its magical utility is defined by its ability to isolate targets, interrupt connections, suppress effects, create silence, and remove paths of interaction.
