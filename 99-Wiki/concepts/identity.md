# Identity

## Definition

Identity is the introductory section of an entity documentation page, serving as a concise summary or overview that establishes the fundamental nature and core characteristics of a subject within the knowledge base.

## Key Characteristics

- **Primary Identifier**: Functions as the first point of reference for users to identify and recognize an entity.
- **Conciseness**: Distills complex, multi-faceted information into a brief, descriptive statement.
- **Contextual Anchoring**: Sets the stage for deeper analysis by providing a high-level perspective before detailed sections follow.
- **Standardization**: Ensures uniform accessibility across the knowledge base by providing a predictable starting point for all documentation.

## Applications

- Serving as a quick-reference snapshot for researchers and users scanning the knowledge base.
- Providing a standard header for all structured entity entries to facilitate automated indexing and human readability.
- Bridging the gap between the search intent of a user and the granular details contained in subsequent technical sections.
