# Void

Void is the Aspect of restraint, separation, silence, boundaries, and accepted absence. It is not the same as [[99-Wiki/concepts/darkness]].

Its Crown is Orr. Void techniques isolate targets, interrupt connections, suppress effects, create silence, and remove paths of interaction.

Void joins [[Ash]] as Deepghost, [[Gale]] as Riftwind, and [[Ember]] as Blackflame through [[Confluences]].
