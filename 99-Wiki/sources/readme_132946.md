## Core Content

This document acts as an index and explanation for the archive folder maintained within the [[entities/nightfall|Nightfall]] project. During the [[concepts/one-shot-migration|one-shot-migration]] process, several files could not be integrated into the new hierarchy because their paths conflicted with existing [[concepts/canonical-destination-file|canonical-destination-file]] locations. 

Rather than discarding these files, the system moved them into a specific [[concepts/legacy-structure|legacy-structure]] folder. This repository preserves previous iterations for historical context and verification. Users are advised that this folder is not the current source of truth; the active project state is held within the canonical file structure, while this documentation serves as a reference point for superseded assets.
