# Return

A dead Echo can return by:

- Reaching a distant Dawn Anchor.
- Having allies recover and ritually prepare the body.
- Accepting conditional Crown or Patron aid.
- Bargaining with [[Last]] to complete unfinished business.
- Using a forbidden door that risks Stain or replacement.

Death creates scars, debts, damaged routes, Echoes, and changed relationships rather than simply deleting progression.
