# Attunement

A first Attunement is a Crown God’s acceptance of a mortal disciple, not a menu selection. The candidate completes a trial proving compatibility with the god’s emotional principle.

- [[Veyra]] tests regret, patience, and concealed truth.
- [[Mareth]] tests grief, debt, and continuity.
- [[Soryn]] tests desire, anger, and action.
- [[Aeral]] tests freedom and risk.
- [[Orr]] tests restraint and the ability to face absence.

The resulting [[Crownlight]] marks the mortal as claimed.
