# Void

## Description

Void is a fundamental aspect associated with absence, emptiness, and the cessation of things. It is instrumental in creating confluences, appearing in recurring pairings with [[entities/gale|Gale]] and [[entities/ember|Ember]]. It represents a state of nothingness that paradoxically defines the boundaries of movement and consumption. By providing a base of non-existence, it serves as the necessary canvas for the interactions of [[concepts/ash|Ash]].
