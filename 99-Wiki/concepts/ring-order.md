# Ring order

## Definition

Ring order is a foundational architectural and geographical standard used to define the spatial organization and progression of the project's world. It establishes a concentric, layered model moving from the core toward the external periphery.

## Key Characteristics

- **Concentric Structure**: Organized in distinct radial tiers emanating from a central point.
- **Fixed Sequence**:
    - **Center**: Vigil/Rise
    - **First**: Hearth
    - **Second**: Gloam
    - **Third**: Murk
    - **Fourth**: Night
    - **Fifth**: Rim
    - **Beyond**: Dark
- **Progression Logic**: Functions as the primary roadmap for world-building, narrative pacing, and game level design.

## Applications

- **Cartography**: Used to structure the layout of the world map.
- **Game Design**: Defines the difficulty curve and zones for player advancement.
- **Narrative Pacing**: Dictates the movement of plot events as they transition through the geographical rings.
