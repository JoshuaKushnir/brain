## Core Content

The Entity Template is a standardized Markdown document designed to serve as a foundational schema for creating entries within the [[entities/nightfall|Nightfall]] project. By establishing a rigid framework, it ensures that all project elements—whether narrative or mechanical—are documented with consistency across the knowledge base. The template mandates a four-section structure: [[concepts/identity|Identity]] for core definitions, [[concepts/history|History]] to anchor the entity within the project's lore, [[concepts/relationships|Relationships]] to map dependencies, and [[concepts/gameplay-expression|Gameplay]] to analyze the specific impacts on player interaction. This systematic approach facilitates navigation, reduces ambiguity, and provides contributors with a clear blueprint for expanding the project's documentation while maintaining high-quality standards.
